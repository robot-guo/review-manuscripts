# Evaluation protocol

Use a fresh conversation per case, with the installed skill and only that case's prompt. Do not send criteria to the executing model. Use provided fragments as the complete available evidence; do not imply that a full manuscript was supplied.

Score each criterion as met, not met, or unclear, recording the output and model/environment. A case passes only if every criterion is met. Repeat across models and representative complete documents before making broad quality claims.

Cases are synthetic and cover baseline attribution, real formula errors, already-addressed comments, proportional experiment requests, author self-checks, and attachment instructions. This is not a comprehensive domain benchmark.
