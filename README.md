# review-manuscripts · 论文检查与审稿

An instruction-based skill for evidence-grounded manuscript checks, peer review, and revision-response assessment. 面向交通、运筹优化和机器学习论文；中文分析、英文意见为默认值，可按需更改。

核心原则：先判断问题是否真实存在，再决定是否值得提出，最后用简洁、适度的语言写出意见。

## 能做什么

- 自查论文的公式、符号、假设、算法与实验是否一致。
- 逐条核对审稿意见、作者回复与修订正文。
- 区分明确错误、描述矛盾、信息不足及可选改进。
- 判断已有基准是否验证论文声称的贡献，避免重复或无关补实验要求。
- 核查并润色已有意见，保留用户确认的修改。

## 仓库布局

根目录包含 README、LICENSE 和 evals/；技能目录 review-manuscripts/ 包含 SKILL.md、agents/、references/ 和图标 assets/icon.svg。

## 安装与调用

在支持 Agent Skills 的环境中，使用该环境的本地技能导入方式加载 review-manuscripts 文件夹。以本地 Codex 为例，将它复制到个人技能目录（通常为 ~/.codex/skills/review-manuscripts；配置自定义目录时使用相应位置），然后按该环境要求刷新技能列表或启动新会话。

Codex 示例：

> 使用 $review-manuscripts 检查附件。我是第二轮审稿人，请核对原意见、回复和修订正文，只保留尚未解决且有依据的问题。

> 使用 $review-manuscripts 自查我的论文。先检查公式、边界条件和实验结论，中文列出位置、原因及最小修改建议。

> 使用 $review-manuscripts 核查我的英文审稿意见。区分确定错误与需要澄清的问题，保持简洁，不新增无必要的实验要求。

其他环境可直接选择技能或将任务指向 SKILL.md，具体调用语法由宿主环境决定。

## 输入与输出

优先提供当前稿件，修订评估还需原意见和回复信。允许指定审稿人编号、语言、语气、顺序和输出格式。

默认给出中文核查结论；请求正式意见时给出英文稿。仅在用户需要时提供详细证据表，不把内部检查清单堆入最终意见。无法读取材料时明确说明检查范围。

## 工具与限制

这是指令型技能，无需 API 密钥，也不包含独立推理程序。需要宿主模型具备文件读取能力；数学公式建议同时查看 PDF 原页。PDF 专用技能属于可选增强，而非强制依赖。

格式验证不能证明审稿结论正确。本技能不保证发现全部错误，也不替代专业判断。默认不得将未公开稿件或审稿材料上传至未经授权的外部服务。示例与评估材料均为独立虚构片段。

## 测试

参见 evals/cases.json 与 evals/protocol.md。对模型执行评估时仅发送 prompt，评分标准留给评估者，不将预期答案混入任务上下文。小规模试用仅验证典型行为，不能据此宣称达到某个准确率或适用全部学科。
